on smelting recipes ("No key cookingtime" crash at 26.2-era schema);
added `cookingtime: 200, experience: 0.1`.

Also kept: `No_Void_Structures_2.0.1.zip` (NOT ported — all 21 structure
files use the Lithostitched mod types `lithostitched:delegating` /
`height_filter`; needs a 26.3-compatible Lithostitched build).
